Lessons:
- Do NOT run a build while editing headers: a sanitizer build that links objects
  from before and after a generated-header change segfaults on a struct-layout
  mismatch (looks like a real bug). Settle the tree, then build.
- The Makefile `-include`s `build/tools/*.d`; keep it that way.
- UBSan flags a deliberate null store in a crash test; use raise(SIGSEGV).
- ASan caught two real bugs I introduced/missed: Histogram bucket array one
  short, and the ResolveAdrpAdd over-read.

volume). Run the sanitizer per-suite (`make build/san/test_test_X && ./build/san/test_test_X test`) and delete each binary, or it dies with "No space left on device".
